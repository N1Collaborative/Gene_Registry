N1C Gene Registry API

The N1C Gene Registry API provides programmatic access to selected datasets within the N1C Gene Registry. The data are freely available for nonprofit, academic, and research use.

Important: The API provides access to registry datasets. Individual entry pages remain available through the Gene Registry website and can be linked directly using their entry identifiers.

Available Endpoints

N-of-1 Projects

GET /api/data?table=N1C_projects

Returns all data from the N-of-1 Projects dataset.

Try it

Marketed Genetic Therapies

GET /api/data?table=marketed_drugs

Returns all data from the Marketed Genetic Therapies dataset.

Try it

Assessed Variants

GET /api/data?table=assessed_variants

Returns all data from the Assessed Variants dataset.

Try it

Assessed Genes & Diseases

GET /api/data?table=assessed_genes_diseases

Returns all data from the Assessed Genes & Diseases dataset, including gene-disease assessments, eligibility, recommended approaches, therapeutic modalities, and therapeutic status.

Try it

Published Genetic Therapies

GET /api/data?table=published_genetic_therapies

Returns all data from the Published Genetic Therapies dataset.

Try it

Search Endpoint

The search endpoint can be used to search registry data for a specific term, such as a gene, variant, disease, or other indexed information.

GET /api/search?q=ATM

Example:

Try search for ATM

Example Usage (JavaScript)

fetch("https://gene-registry.onrender.com/api/data?table=N1C_projects")
  .then(res => res.json())
  .then(data => console.log("N-of-1 Projects:", data));


fetch("https://gene-registry.onrender.com/api/data?table=marketed_drugs")
  .then(res => res.json())
  .then(data => console.log("Marketed Genetic Therapies:", data));


fetch("https://gene-registry.onrender.com/api/data?table=assessed_variants")
  .then(res => res.json())
  .then(data => console.log("Assessed Variants:", data));


fetch("https://gene-registry.onrender.com/api/data?table=assessed_genes_diseases")
  .then(res => res.json())
  .then(data => console.log("Assessed Genes & Diseases:", data));


fetch("https://gene-registry.onrender.com/api/data?table=published_genetic_therapies")
  .then(res => res.json())
  .then(data => console.log("Published Genetic Therapies:", data));


fetch("https://gene-registry.onrender.com/api/search?q=ATM")
  .then(res => res.json())
  .then(data => console.log("Search Results:", data));

Automated Assessment Tools

Automated Assessment Tools are currently presented as a separate registry section and are not currently exposed through the data API. Public benchmarking reports can be accessed through the Gene Registry website.
